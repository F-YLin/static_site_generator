# static_site_generator
The static site generator takes raw content files like Markdown and images and turn them into a static website

Specifically, this static site generator will take a directory of Markdown files
(one dor each web page) and build a directory of HTML files because according to
the instruction, writing raw HTML files are painful.

This is a project done with instruction from bootdev. I do not claim full credit, but it is hopefully a great experience for me to learn. Onward!`
